# Roadmap

## Stage 0: Repository Foundation

- Define project vision, contribution model, and responsible research principles.
- Create the six research theme pages.
- Add project templates for researchers and engineers.
- Add minimal JSON Schemas for observations, individuals, devices, and deployment sites.
- Add GitHub issue templates for proposals, hardware integrations, datasets, and bugs.

## Stage 1: Research Project Intake

- Collect real research questions from field teams and conservation partners.
- Convert promising questions into structured project proposals.
- Identify species, sites, device constraints, data availability, and ethical risks.
- Build a public index of active and proposed projects.

## Stage 2: Shared Data and Annotation Patterns

- Refine schemas based on real datasets.
- Define annotation formats for images, audio clips, tracking records, and environmental observations.
- Add dataset cards and release checklists.
- Publish example synthetic or low-risk datasets for development.

## Stage 3: Reference Implementations

- Add small, tested modules only after real use cases exist.
- Prioritize ingestion, validation, annotation conversion, and evaluation helpers before large models.
- Document deployment recipes for edge devices and field stations.

## Stage 4: Community Programs

- Maintain a project gallery.
- Host challenge datasets where ethically appropriate.
- Publish field deployment case studies.
- Build reusable workflows for data review, model evaluation, and conservation reporting.
