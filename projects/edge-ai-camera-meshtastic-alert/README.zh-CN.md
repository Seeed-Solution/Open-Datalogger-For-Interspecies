# 边缘 AI 摄像头到 Meshtastic 告警 Demo

[English](README.md)

这个 demo 用来验证 Open Datalogger For Interspecies 中一个很小但很关键的野外链路：

```text
边缘 AI 摄像头识别目标
-> 本地 GPIO 信号触发
-> Meshtastic 节点发出告警
-> 野外接收节点显示事件
```

在公司环境里的试点中，reCamera Pro 用来监测办公室附近是否出现野猫。当识别到猫之后，摄像头会触发一个 GPIO 输出，连接到 Meshtastic 发射节点；告警再通过 Meshtastic 网络发送到 Wio Tracker L1 Pro 接收节点。

这里的猫是一个安全、容易复现的代理目标。真正到野外时，同样的链路可以替换成老虎、狼、重点保护动物，或者疑似偷猎者等目标。这个 demo 的目标不是证明“老虎识别模型已经可用”，而是验证一条完整链路：边缘识别、本地物理触发、离线网络传输、接收端提示，这些环节可以组合成一个可部署的工作流。

## 为什么这个 demo 有意义

很多野外摄像头可以拍下照片或视频，但研究人员往往要等到回收设备或下载数据后，才知道现场发生了什么。对于需要快速响应的场景，仅仅“存下来”是不够的。

这个 demo 验证的是更快的一种模式：

- 摄像头在本地识别目标；
- 触发时保存现场照片作为证据；
- 输出一个简单的 GPIO 信号；
- 低功耗无线网络把事件发出去；
- 接收节点收到提示，研究人员可以知道“现在发生了什么”。

未来这个模式可以用于目标物种出现提醒、人兽冲突预警、车辆/人员进入提醒，或者让另一个采样设备按需启动。

## 当前试点场景

| 项目 | 当前设置 |
|---|---|
| 场景 | 公司/办公室附近 |
| 代理目标 | 野猫 |
| 野外类比 | 老虎、狼、疑似偷猎者 |
| 边缘设备 | reCamera Pro |
| 通信网络 | Meshtastic |
| 接收节点 | Wio Tracker L1 Pro |
| 触发信号 | GPIO188，3.3 V 高电平脉冲 |
| 高电平持续时间 | 3 秒 |
| 冷却时间 | 60 秒 |
| 证据记录 | 本地触发照片和事件日志 |

## 数据链路

```text
reCamera Pro
  AI 推理结果：cat/person/etc.
  触发过滤：cat
  抓拍：保存本地 JPG
  GPIO188：输出高电平脉冲
        |
        v
Meshtastic 发射节点
  读取 GPIO 信号
  发送告警消息
        |
        v
Wio Tracker L1 Pro 接收节点
  接收野外告警
  显示或转发事件
```

## 已验证内容

- 摄像头可以持续运行边缘 AI 推理。
- 本地程序可以读取 AI 推理结果。
- 指定目标类别可以触发 GPIO 脉冲。
- 触发瞬间可以保存照片，后续用来判断误报。
- GPIO 输出可以作为 Meshtastic 设备的输入信号。
- Meshtastic 网络可以把告警送到 Wio Tracker L1 Pro 接收节点。

## 还没有证明的内容

- 还没有证明老虎或狼识别模型已经达到野外生产可用水平。
- 还没有完成误报率、漏报率、长期准确率评估。
- 还没有定义完整的野外保护数据协议。
- 不能替代专家对照片、地点和敏感物种信息的审核。
