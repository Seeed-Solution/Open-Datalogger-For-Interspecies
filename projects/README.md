# Projects

Projects are the bridge between research questions and reusable technology.

## Project Lifecycle

| Stage | Meaning |
|---|---|
| Proposal | Research question and constraints are being defined |
| Scoping | Data, devices, risks, and owners are identified |
| Pilot | Small field or dataset experiment is underway |
| Active | Project has active data collection or implementation |
| Completed | Results, limitations, and reusable outputs are documented |

## Starting a Project

Use `projects/project-template/` or the GitHub project proposal issue template. A project should start with a specific research question, not a preferred model.
