# Reference Implementations

This directory is reserved for small, reusable implementations that have been validated by real projects.

## Admission Criteria

Before adding code here, confirm that:

- The workflow solves a repeated project need.
- Input and output formats are documented.
- Sensitive data handling is clear.
- Minimal tests or validation examples are included.
- The implementation is small enough to maintain.
