# Device Overview

AI in the Wild supports multiple field device types. Device choice should follow the research question and field constraints.

| Device Type | Typical Data | Useful For |
|---|---|---|
| Camera nodes | Images, video | Detection, counting, behavior, Re-ID |
| Acoustic nodes | Audio clips, continuous recordings | Species presence, vocal behavior, stress signals |
| Tracking devices | GPS, LoRa, VHF, BLE | Movement, home range, social proximity |
| Environmental sensors | Weather, water, soil, vegetation indicators | Habitat condition, carrying capacity |

Each project should document device metadata using `schemas/device-metadata.schema.json`.
