# Time-Series Analysis

Time-series analysis helps connect movement, activity, environment, and behavior across time.

## Common Tasks

- Activity rhythm analysis.
- Movement path summaries.
- Environmental trend detection.
- Population trend estimation.
- Anomaly detection.
- Forecasting.

## Field Constraints

- Missing data and device failures.
- Irregular sampling intervals.
- Timezone and clock drift issues.
- Seasonal patterns.
- Small sample sizes for rare events.

## Recommended Practice

- Record sampling interval and timestamp source.
- Keep missingness visible instead of silently imputing.
- Separate observation time from upload time.
- Report uncertainty and data gaps.
