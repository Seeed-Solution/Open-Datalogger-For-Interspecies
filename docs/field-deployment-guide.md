# Field Deployment Guide

This guide captures practical considerations for deploying AI-related sensing systems in wildlife research.

## Before Deployment

- Confirm research permits, site access, and data collection permissions.
- Define the research question and required evidence.
- Choose devices based on species behavior, habitat, weather, battery, and maintenance constraints.
- Decide what data is public, generalized, controlled, or restricted.
- Create a retrieval and failure plan.

## Device Planning

Document each device with:

- Device ID and type.
- Firmware or software version.
- Sensor configuration.
- Time synchronization method.
- Power source and expected runtime.
- Storage capacity and data rotation behavior.
- Connectivity method.

## Site Planning

Document each deployment site with:

- Site ID and general location.
- Habitat type.
- Sensitivity level.
- Installation date and retrieval date.
- Human disturbance risk.
- Environmental conditions.

## After Deployment

- Validate timestamps and device IDs before analysis.
- Record missing data and device failures.
- Review whether sensitive location data should be generalized.
- Keep raw data, derived annotations, and model outputs traceable.
